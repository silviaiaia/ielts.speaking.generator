A web app that generates IELTS Speaking practice questions on demand for
Parts 1, 2 and 3. Nothing to install — pick a part, and a fresh question
set is generated by Gemini.

**[→ Try it](https://ielts-speaking-generator.vercel.app/)**

## Features

- **Part 1** — everyday warm-up questions with follow-ups.
- **Part 2** — a full cue card with bullet-point prompts for the
  two-minute monologue, plus the examiner's likely follow-ups.
- **Part 3** — abstract discussion questions extending the Part 2 topic.

## How it works

```
Browser ──POST /api/generate_question──▶ Vercel serverless function
                                                    │
                                          Gemini API (key server-side)
                                                    │
Browser ◀──────── generated question ───────────────┘
```

The browser never sees the Gemini API key. Calling the model directly
from client-side JavaScript would expose it to anyone opening DevTools,
so all requests are proxied through a serverless function that reads the
key from an environment variable.

The model name is also an environment variable rather than a constant —
when `gemini-2.0-flash` was retired, swapping it took a config change
instead of a code change.

## Running locally

```bash
git clone https://github.com/silviaiaia/ielts.speaking.generator.git
cd ielts.speaking.generator
npm install

echo "GEMINI_API_KEY=your_key_here" > .env
npm run dev
```

Get a key from [Google AI Studio](https://aistudio.google.com/apikey).
The API is then available at `http://localhost:3000`:

```bash
curl -X POST http://localhost:3000/api/generate_question \
  -H "Content-Type: application/json" -d '{"part":"part1"}'
```

## Built with

Vanilla JS front end, Express on Vercel serverless functions,
[`@google/genai`](https://www.npmjs.com/package/@google/genai).
